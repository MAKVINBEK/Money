# Akcha

Akcha — мобильное PWA-приложение для личного учёта финансов. Данные остаются на устройстве пользователя; сервер, аккаунт и внешняя база данных не требуются.

## Разработка

Требуется Node.js 22.12 или новее.

```bash
npm ci
npm run dev
```

Основные проверки:

```bash
npm run lint
npm run build
npm run preview
```

Service Worker и офлайн-режим включаются в production-сборке. Для их проверки соберите приложение и откройте локальный preview, затем используйте раздел Application в инструментах разработчика браузера.

## PWA-иконки

Исходник всех иконок находится в `public/logo.svg`. После его изменения пересоздайте PNG и favicon установленным генератором:

```bash
npm run generate:pwa-assets
```

Конфигурация генерации хранится в `pwa-assets.config.ts`. `manifest.id`, `scope` и `start_url` намеренно остаются равными `/`, чтобы обновления сохраняли идентичность установленного приложения на том же домене.
